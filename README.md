# StudySpace — Student Productivity Website

**Created by:** Anurag Kalyan  
**Project:** College assignment — Design, Develop, and Host a Website  
**Technology:** HTML, CSS, JavaScript  
**Hosting:** GitHub Pages (free)

## Features
- Add, complete, filter, and delete study tasks.
- Mark task priority as High, Medium, or Low.
- Focus timer with 25-minute focus, 5-minute short break, and 15-minute long break modes.
- Focus minutes and task completion statistics.
- Weekly goals checklist with progress.
- Light/dark theme toggle.
- Responsive layout for mobile and desktop.
- Tasks, theme, goals, and focus minutes save in the browser using `localStorage`.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. No build tools or installation are required.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com.
2. Ask your teacher/class representative for your exact section (for example, `CSE-A` or `Section-2`) before finalising the repository name.
3. Create a **public** repository. Suggested name: `anurag-kalyan-section-student-productivity`. Replace `section` with your actual section, using lowercase letters and hyphens, for example `anurag-kalyan-cse-a-student-productivity`.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root (not inside another folder).
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. GitHub will show the published URL in Settings → Pages.

Your URL will normally be:
`https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`

Example only (replace both values):
`https://your-github-username.github.io/anurag-kalyan-cse-a-student-productivity/`

The URL includes your name and section in the repository path. GitHub Pages uses your GitHub username for the domain, so the full URL cannot be guaranteed until your username and section are known.

## Short project description for submission
StudySpace is a responsive student productivity dashboard designed to help students organise their academic workload. It combines task management, priority labels, a Pomodoro-style focus timer, weekly goal tracking, and progress statistics in one interface. The project is built with HTML for structure, CSS for styling and responsive design, and JavaScript for interactive behaviour. Browser local storage keeps the student's tasks and preferences available on the same device without requiring a backend or database.
